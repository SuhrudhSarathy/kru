Install

kru is a single static binary. Pick whichever route suits you.

Prebuilt binaries

Download the archive for your system from the latest release.

SystemArchive
macOS, Apple siliconkru-aarch64-apple-darwin.tar.gz
macOS, Intelkru-x86_64-apple-darwin.tar.gz
Linux, x86_64kru-x86_64-unknown-linux-musl.tar.gz
Linux, ARM64kru-aarch64-unknown-linux-musl.tar.gz
Windows, x86_64kru-x86_64-pc-windows-msvc.zip

The Linux binaries are static and run on any distribution. Each archive has a .sha256 file beside it to verify the download.

macOS and Linux

target=aarch64-apple-darwin   # pick from the table above
mkdir -p ~/.local/bin
curl -fsSL "https://github.com/SuhrudhSarathy/kru/releases/latest/download/kru-$target.tar.gz" \
  | tar xz -C ~/.local/bin kru

Make sure ~/.local/bin is on your PATH. If a browser-downloaded binary is blocked on macOS, clear the quarantine flag: xattr -d com.apple.quarantine ~/.local/bin/kru.

Windows

Unzip kru-x86_64-pc-windows-msvc.zip and put kru.exe in a folder on your PATH.

From source

With Rust 1.89 or newer:

cargo install --git https://github.com/SuhrudhSarathy/kru --locked

Shell completion

Tab completes commands and flags, plus your bucket names, task numbers and setting names (e.g. kru task list -b <Tab>). Add the line for your shell to its startup file:

source <(COMPLETE=zsh kru)          # ~/.zshrc
source <(COMPLETE=bash kru)         # ~/.bashrc
COMPLETE=fish kru | source          # ~/.config/fish/config.fish

Check it works

$ kru --version
