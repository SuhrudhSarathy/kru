Buckets

A bucket is a named list of tasks: a project, a context, an area of life.

kru bucket add work          # create; the first one becomes active
kru bucket list              # * marks the active bucket
kru bucket use home          # default for `kru task add`
kru bucket rename work job
kru bucket remove job        # asks first if it has open tasks; --force skips
  • Names are matched case-insensitively.
  • task add fails if the bucket doesn't exist, or if none is given and none is active.
  • Removing a bucket with open tasks needs --force and deletes those tasks.
  • Merging devices (see Syncing) combines buckets that share a name.
  • A bucket can be made private: encrypted and hidden.

Move a task between buckets with kru task move <task> -b <bucket>, or m in the TUI.
