Terminal UI

Run kru with no command to open it.

The screen has three panes: Buckets, Tasks (open tasks of the selected bucket) and Done (finished tasks). The footer always shows the keys available right now, and the latest message (green) or error (red).

Screens

Moving around

KeyAction

Buckets pane

KeyAction

eRename the selected bucket
r / DelRemove the bucket and its tasks (asks first)
uMake it the active bucket

Tasks and Done panes

KeyAction
aAdd a task to the selected bucket
spaceToggle done / reopen
eOpen the field editor for the task
sEdit status
pCycle priority
dEdit due date (type fri, 3d, …)
mMove to another bucket (type its name)
oOpen the task's markdown notes in your editor
r / DelRemove the task (asks first)

Syncing

S syncs with your git remote. With autosync on, the TUI also syncs in the background every five minutes.

The field editor

e opens a form with every field of the task.

KeyAction
j/kPrevious / next field
h/l or spaceChange an option (priority, status)
EnterType into a text field (description, context, due)
EscFinish

Typing text

KeyAction
EnterSave
Alt+Enter or Ctrl+JNew line (in multi-line context)
EscCancel / undo typing
Ctrl+A / Ctrl+EStart / end of line
Alt+← / Alt+→ (or Alt+B/F)Word left / right
Ctrl+W / Alt+BackspaceDelete word left
Ctrl+U / Ctrl+KDelete to start / end of line

Confirmations

Destructive actions ask first. Only y confirms, so a stray Enter can never apply a change. n or Esc cancels.

Colours

The CLI and TUI share one palette so a task looks the same in both: red for danger (overdue), yellow for warnings, green for success, magenta for in-progress, cyan for numbers and info, grey for muted values.
