kru कृ

Tasks, organised in buckets. A command-line tool and a terminal UI in one small binary.

# add a task from the shell
$ kru bucket add work
$ kru task add -d "Write quarterly report" -p high --due fri

# or just open the terminal UI
$ kru

What it looks like

What it does

Terminal UIVim-style keys, three panes, an inline field editor. Run kru with no arguments. Scriptable CLIEvery command has --json, stable ids and predictable exit codes. Private bucketsEncrypt a bucket with a password (Argon2id + XChaCha20-Poly1305). Git syncKeep devices in step through any private git repo, with automatic merging. Rich tasksPriority, status, natural due dates (fri, 3d), context and markdown notes. Agent friendlyShips a SKILL.md so LLM agents can drive it safely.

The model in 30 seconds

  • A task has a description, priority, status, optional due date, free-form context and an optional markdown notes file.
  • Every task lives in a bucket (e.g. work, home). One bucket is active; task add uses it by default.
  • Tasks are shown ordered by urgency: open before done, then earliest due date, then priority.
  • Done tasks are cleaned up automatically after 7 days.
  • Data is plain JSON files in one directory, so it is easy to back up or sync.

The name

kru comes from the Sanskrit root कृ (kṛ), “to do”, the root of karma (action) and kartavya (what is to be done), which is what a todo list holds.
