FAQ & troubleshooting

My tasks disappeared

  • Private bucket? Locked private buckets are completely hidden. Run the command with --unlock, or press P in the TUI.
  • Different store? kru path shows which directory is in use. A leftover KRU_DIR in your shell, or a changed dir setting, points kru somewhere else. kru config shows where each value comes from.
  • Done tasks? task list hides them. Add --all. They're deleted after 7 days.

A task's number changed

Numbers are positions, recomputed bucket by bucket. Use the task's id (or the start of it) whenever you need something stable. kru task show 3 --json | jq -r .id gets it.

no bucket given and no active bucket set

Create one (kru bucket add work) or pick one (kru bucket use work), or pass -b.

macOS refuses to run the downloaded binary

xattr -d com.apple.quarantine ~/.local/bin/kru

kru: command not found

Add the install folder to your PATH, e.g. export PATH="$HOME/.local/bin:$PATH" in your shell's startup file.

Sync problems

MessageFix
git isn't installedInstall git and make sure it's on your PATH
sync isn't set up for this storeRun kru sync init <remote-url> first
this store already syncs with <url>sync init was given a different remote than the one already configured
git fetch failed / git push failedNetwork or access problem. Nothing is lost; check your SSH key or token and retry

A background sync (autosync) logs to sync.log in the store directory.

I forgot my private bucket's password

It can't be recovered: the tasks are encrypted with a key derived from it, and there is no backdoor. Remove the bucket and start again.

"written by a newer kru"

Another device (or a newer install) saved the data in a newer format. Upgrade kru on this device. Don't edit the files by hand.

The TUI won't take Alt+Enter for a new line

Some terminals send Enter and Alt+Enter as the same key. Use Ctrl+J, which works everywhere.

The editor that opens isn't the one I want

kru config set editor "code --wait"

Where do I report a bug?

GitHub issues. Include kru --version and your OS.
