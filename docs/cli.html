CLI reference

Every command. kru <command> --help is always the authority.

Global options

FlagMeaning
--jsonPrint JSON instead of text. Works anywhere on the command line.
--unlockAsk for the password of private buckets and show them for this command
-h, --helpHelp
-V, --versionVersion

kru with no command opens the TUI (with --json it is an error instead).

kru task

CommandWhat it does
task addAdd a task. -d required; -b bucket (default: active); plus -c -p -s --due
task list (ls)List tasks. Filters: -b bucket, -s status, -p priority, -q text, -a include done
task show <task>Every detail of a task
task mark <task> (edit)Change fields with -d -c -p -s --due. All-or-nothing; setting an unchanged value is a no-op
task ctx <task> [text]Show context; -a text appends a line; text replaces (asks unless -f)
task md <task>Open the markdown notes in your editor (creating them). --path prints the path; --remove deletes (asks unless -f)
task done <task>…Mark one or more tasks done
task move <task> -b <bucket> (mv)Move to another bucket
task remove <task>… (rm)Remove tasks

kru bucket

CommandWhat it does
bucket add <name> [--private]Create a bucket (optionally encrypted)
bucket private <name>Make an existing bucket private
bucket list (ls)List buckets; * marks the active one
bucket use <name>Make it the default for task add
bucket rename <name> <new>Rename
bucket remove <name> [--force] (rm)Remove a bucket and its tasks

kru sync

CommandWhat it does
syncCommit, fetch, merge and push
sync init <remote>Set up syncing with a git remote, then sync
sync statusWhere syncing stands, without touching the network

kru config

CommandWhat it does
config / config listEvery setting, its value and its source
config get <key>One setting
config set <key> <value>Change a setting
config unset <key>Fall back to env or default
config pathThe config file's path

Other

CommandWhat it does
prune [--days N]Delete done tasks completed more than N days ago (default 7)
pathPrint where kru stores its data

Exit codes

CodeMeaning
0Success; JSON (with --json) on stdout
1Failure; nothing on stdout; stderr is one line starting Error:
2Bad arguments; stderr starts error:
