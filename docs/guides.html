Workflows

Recipes that combine the pieces. Each is self-contained.

A daily routine with the TUI

  1. Open kru. Tasks are already ordered most urgent first, so the top of Tasks is what to do next.
  2. Press s on what you start (in-progress), space when it's done.
  3. Capture new work with a; set the due date with d (fri, 3d, tomorrow).
  4. Put long-running detail in notes with o rather than in the description.
  5. Finished tasks sit in Done for a week, then vanish. Reopen one with space.

Syncing a laptop and a desktop

# once: make an EMPTY PRIVATE repo, e.g. github.com/you/my-tasks
laptop$  kru sync init git@github.com:you/my-tasks.git
desktop$ kru sync init git@github.com:you/my-tasks.git   # same URL
# from now on
kru config set autosync on     # background sync after changes

If both edit the same task before syncing, kru merges field by field, and the later edit wins for a field both touched. See Syncing.

Quick capture from the shell

alias t='kru task add -d'
t "Call the dentist" --due tomorrow -p medium

Show what's due in your prompt or status bar

# count of open tasks due within a day
kru task list --json | jq --arg c "$(date -u -d '+1 day' +%FT%TZ)" \
  '[.[] | select(.due != null and .due <= $c)] | length'

On macOS replace date -u -d '+1 day' with date -u -v+1d.

A morning reminder with cron

# crontab -e : weekdays at 9, print overdue/today tasks (mail or notify-send as you like)
0 9 * * 1-5  kru task list --json | jq -r '.[] | select(.due != null) | "\(.due[:10])  \(.description)"' | sort | head

Moving a project to its own bucket

kru bucket add launch
kru task list -q "launch" --json | jq -r '.[].id' | xargs -I{} kru task move {} -b launch

Keeping sensitive tasks private

kru bucket add finance --private
kru task add -b finance -d "File taxes" --unlock
