Rust library

The kru crate is also a library, the same one the CLI and TUI are built on.

The API is young and may change between releases. Pin a version or a git revision.

Depend on it

[dependencies]
kru = { git = "https://github.com/SuhrudhSarathy/kru" }

Modules

ModuleWhat's in it
kru::taskTask, Priority, Status
kru::bucketBucket: add, get, search, filter tasks
kru::storeStore: the persistent store (Store::open, save, buckets, notes, private buckets)
kru::syncSyncing and the merge
kru::configSettings
kru::privacySealing and unsealing buckets

Example

use jiff::{Timestamp, ToSpan};
use kru::bucket::Bucket;
use kru::task::{Priority, Status, Task};

let mut home = Bucket::new("Home");
let id = home.add(
    Task::new("Buy groceries")
        .with_priority(Priority::High)
        .with_due(Timestamp::now() + 24.hours()),
);
home.get_mut(id).unwrap().set_status(Status::InProgress);

for task in home.search("groceries") {
    println!("{}", task.description);
}

A longer, runnable version lives in examples/api.rs: cargo run --example api.

Build the API reference locally with cargo doc --open.
