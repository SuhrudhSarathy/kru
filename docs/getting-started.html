Getting started

A five minute tour of the everyday commands.

1. Create a bucket

Tasks live in buckets, so make one first. The first bucket you create becomes the active one.

$ kru bucket add work
$ kru bucket add home
$ kru bucket list

2. Add tasks

$ kru task add -d "Write quarterly report" -p high --due fri
$ kru task add -d "Pay rent" -b home --due 3d -c "Landlord: Sam"

Without -b, the active bucket is used. Change it with kru bucket use home. See Tasks & fields for every flag and the due-date formats.

3. Look at them

$ kru task list                  # open tasks, most urgent first
$ kru task list -b home -p high  # filter
$ kru task list -q report        # search descriptions
$ kru task list --all            # include done tasks
$ kru task show 1                # every detail of task #1

4. Change and finish them

$ kru task mark 1 -s in-progress -p medium
$ kru task ctx 1 -a "Draft shared with Priya"    # append a note line
$ kru task md 1                                  # open a markdown notes file in your editor
$ kru task move 1 -b home
$ kru task done 1 2

Numbers shift, ids don't. Tasks are numbered bucket by bucket, so adding or removing a task can change other tasks' numbers. Anything that takes a task also accepts its id (or the start of it). Prefer ids in scripts.

5. Use the terminal UI

$ kru

Press a to add, space to toggle done, x to expand a task, q to quit. Full key list in Terminal UI.

6. Keep devices in step (optional)

Create an empty private git repository (e.g. on GitHub), then on each device:

$ kru sync init git@github.com:you/my-tasks.git

Details in Syncing. Requires git.
