Changelog

Release notes. Binaries for each release are on the releases page.

0.3.0

  • Private buckets: encrypt a bucket with a password (Argon2id + XChaCha20-Poly1305). Hidden unless --unlock is given; TUI keys P/L. Private buckets sync encrypted.
  • Notes of tasks in private buckets are kept inside the encrypted bucket.

Since 0.1.0

  • Git sync: kru sync, sync init, sync status; id-based three-way merge; autosync setting.
  • Shell completion for commands, flags, bucket names, task numbers and setting names.
  • Markdown notes per task (task md) and multi-line context.
  • Agent support: --json everywhere, stable ids, and SKILL.md.
  • Store format versioning with automatic migration.
  • Prebuilt binaries for macOS, Linux (static) and Windows.

0.1.0

First release: CLI and terminal UI with buckets, tasks, priorities, statuses and due dates.
